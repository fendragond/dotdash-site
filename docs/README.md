## Principe

Le backlog vit dans le repo qu'il pilote. Le brief et le backlog du projet (`dotdash_brief.md`, `dotdash_backlog.md`) ont été clonés depuis les templates du starter, qui ne sont pas conservés ici. Le REX technique (`cursor_gotchas.md`) est chargé au bootstrap de chaque nouveau projet Cursor.
